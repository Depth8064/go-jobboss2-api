# Security Policy

## Supported Versions

This project supports the latest code on the main branch.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Report vulnerabilities by emailing the maintainer and include:

1. Description of the issue.
2. Reproduction steps or proof of concept.
3. Potential impact.
4. Suggested remediation, if known.

You should receive an initial response within 5 business days.
